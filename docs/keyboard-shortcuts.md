# Keyboard shortcuts

Shortcuts apply while the **shell chrome** has focus. Once you click inside a
service, keystrokes belong to that site (that is what a browser tab should do);
press `Ctrl+Tab` or click the tab strip to return to the chrome. On macOS use
`⌘` instead of `Ctrl`.

| Keys | Action |
|------|--------|
| `Ctrl+T` | Open the service picker |
| `Ctrl+B` | Toggle the service sidebar |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | Next / previous tab |
| `Ctrl+1` … `Ctrl+9` | Jump to tab *n* |
| `Ctrl+W` | Close the active tab |
| `Ctrl+R` / `F5` | Reload the active tab |
| `Ctrl+=` / `Ctrl+-` / `Ctrl+0` | Zoom in / out / reset (active tab) |
| `Ctrl+,` | Open settings |
| `Esc` | Close dialogs, sidebar and settings |
| `?` | Show the shortcut reference |

Global (OS-wide) shortcut, configurable in **Settings → General**:
`CommandOrControl+Shift+A` shows or hides the app.

Mouse: middle-click a tab to close it; right-click a tab for reload, zoom,
copy URL, hibernate and close actions; drag tabs to reorder.
