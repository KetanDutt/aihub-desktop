# Packaging & distribution

Packaging is handled by [electron-builder](https://www.electron.build), configured
in `package.json` under the `build` key.

## Targets

| Platform | Target | Output |
|----------|--------|--------|
| Windows | NSIS installer (x64) | `dist/AI Hub Desktop-<ver>-win-x64.exe` |
| macOS | DMG (x64 + arm64) | `dist/*.dmg` |
| Linux | AppImage + deb | `dist/*.AppImage`, `dist/*.deb` |

```bash
npm run build:win     # or build:mac / build:linux / build (current OS)
npm run pack          # unpacked directory only (fast iteration)
```

## One-click build

For a build that needs no prior setup, use the guided script. It checks Node,
installs dependencies and the Electron runtime, regenerates the service
catalogue and its cached icons, runs lint + tests, then builds:

```bash
npm run one-click-build          # installer for the current OS
npm run one-click-build -- --all # every target this host can produce
npm run one-click-build -- --dir # unpacked build, no installer
npm run one-click-build -- --fast# skip lint + tests
npm run build:all                # alias for --all
```

Double-click entry points: **`BUILD.bat`** (Windows) and **`BUILD.sh`**
(macOS / Linux) at the repository root; both forward their flags to the script.
Artefacts and their sizes are listed when the build finishes. Nothing is
published unless you pass `--publish`.

The NSIS installer is per-user, allows choosing the install directory and
registers the `aihub://` protocol.

## Assets

- `build/icon.ico` (Windows), `build/icon.png` (mac/Linux), `build/tray.png`
  are generated by `npm run icons` (pure Node, no ImageMagick). `build/logo.svg`
  is the vector source of truth.
- `data/*.json` is bundled via `extraResources` so the app is fully functional
  offline and on first launch. This includes `data/catalog.json`, the audited
  menu catalogue.
- `assets/icons/<service>.<ext>` ships inside the asar (`build.files`) so the
  tab strip and service picker paint their icons instantly, offline, with no
  network request. Regenerate both with `npm run services:audit`.

## Auto-update

`electron-updater` publishes/consumes GitHub releases (`build.publish`). Update
checks only run in packaged builds; the dev build logs
"Auto-update disabled". The About panel shows live update state and offers a
manual check.

## Windows one-click scripts

**Fastest path:** double-click `RUN.bat` at the repository root. It checks and
installs Node.js 20+, npm dependencies and the Electron runtime, runs the
environment doctor, then launches the desktop app (web UI shell).

Finer-grained helpers live in `scripts/windows/` — see
`scripts/windows/README.md`. `Setup.bat`, `Run.bat`, `RunServer.bat`, `Build.bat`, `Test.bat`,
`Dev.bat` and `Clean.bat` detect/install Node.js and dependencies, then perform
the action - designed to be double-clicked with no terminal experience.

Cross-platform equivalent (Node must already be installed):

```bash
npm run one-click     # scripts/one-click-run.js
```

## Code signing / notarization

Not configured. To ship signed Windows builds, add your certificate to the
`win` config; for macOS notarization, add `notarize` credentials. See the
electron-builder docs.
